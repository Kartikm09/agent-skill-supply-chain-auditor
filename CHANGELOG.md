## [0.1.0] - 2026-07-27

### Added

- Static CLI and Python API for Agent Skill bundles and MCP JSON.
- Seventeen metadata, instruction, secret, command, dependency, permission, filesystem, provenance,
  licensing, and transport rules.
- Bounded traversal that skips symlinks and never executes inspected code.
- Deterministic JSON, Markdown, SARIF, Agent-SBOM, and Mermaid reports.
- Irreversible evidence redaction and relative-path reporting.
- Ten labelled synthetic fixtures and measured rule-level benchmark.
- Unit, integration, negative, CLI, and reporter tests.
- Functional static dashboard and open-source project documentation.
